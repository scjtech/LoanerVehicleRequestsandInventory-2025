# Loaner Vehicle Request & Inventory Management

A scoped ServiceNow application designed to manage loaner vehicle inventory and provide users with a streamlined way to request available vehicles through the Service Catalog.

## Project Overview

The Loaner Vehicle Request & Inventory Management application was created to replace manual vehicle-request and inventory processes with a centralized ServiceNow solution.

The application allows users to submit loaner vehicle requests while giving support staff tools to manage vehicle availability, servicing, and request fulfillment.

## Key Features

- Custom scoped ServiceNow application
- Loaner vehicle inventory management
- Service Catalog request experience
- Custom Service Portal
- Custom tables for vehicle and service records
- Automated field population
- Client Scripts
- Script Includes
- JavaScript-based UI Actions
- Roles and access controls
- Request and fulfillment workflow
- Vehicle servicing tracking
- Source Control / GitHub

## Application Functionality

Users can submit a request for a loaner vehicle through the Service Catalog.

The application supports:

1. Viewing and requesting available vehicles.
2. Capturing vehicle and request information.
3. Automatically populating related data based on user selections.
4. Managing vehicle availability and inventory records.
5. Tracking vehicles that require servicing.
6. Supporting request fulfillment through a centralized ServiceNow application.

## Automation & Development

JavaScript and ServiceNow development tools were used to reduce manual work throughout the application.

Examples include:

- Client Scripts for dynamic form behavior
- Script Includes for reusable application logic
- UI Actions for inventory-related processes
